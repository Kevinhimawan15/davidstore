# DavidStore — staging prototipe

Situs: https://kevinhimawan15.github.io/dstore-staging/

**Semua data di sini adalah CONTOH.** Produk, harga estimasi, harga modal, margin per kategori, rekening, nomor WhatsApp, dan pesanan adalah angka rekaan untuk menguji alur — bukan angka David. Jangan transfer uang.

- Foto produk: foto referensi dari situs brand/toko (sumber di `assets/products/manifest.json`), akan diganti foto dari David/distributor.
- Data pesanan tersimpan di browser masing-masing pengunjung (localStorage), kecuali disambungkan ke Google Sheet lewat Pengaturan.
- Repo ini hanya salinan folder `prototype/` dari repo utama (private).
